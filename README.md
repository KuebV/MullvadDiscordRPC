# ⚡ Blazingly Fast

MullvadRPC hooks directly into your local Mullvad VPN session and broadcasts your encrypted dominance straight to Discord Rich Presence in real time.

No cloud relay.
No telemetry.
No nonsense.

Built for:

- 🧠 Developers
- 🎮 Gamers
- 🕶️ Privacy minimalists
- ☕ Linux rice enthusiasts

# 🔒 Optionally Secure

Why hide your VPN usage when you can flex it?

MullvadRPC can display:

- 🌍 Connected country & city
- 🖥️ VPN server hostname
- 📶 Session uptime

Or keep it minimal and mysterious.
